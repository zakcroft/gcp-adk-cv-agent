# CV-Agent Frontend (Phase 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A one-page React SPA to upload a CV and a job description, wait while the pipeline runs, then read and download the improved CV — with a rerun button that guards against discarding an undownloaded draft.

**Architecture:** React + Vite + TypeScript SPA in a top-level `frontend/` package. It talks to the Phase-1 API (`POST /jobs` → `GET /jobs/{id}` polling → `GET /jobs/{id}/cv`) through a Vite dev proxy, so there is no CORS to configure locally. A small state machine drives one page: `idle → running → done | failed`.

**Tech Stack:** React 19, Vite 7, TypeScript 5, Vitest 3 + @testing-library/react + jsdom.

## Global Constraints

- Consumes the API from `docs/superpowers/plans/2026-08-07-api-phase1.md`: `POST /jobs` (multipart fields `cv`, `jd`) → `{ job_id }`; `GET /jobs/{id}` → `{ status: "running"|"done"|"failed", error: string|null }`; `GET /jobs/{id}/cv` → CV text.
- Dev talks to the API via a Vite proxy (`/jobs` → `http://localhost:8000`); the FE uses relative URLs only. Production base URL is a later concern (spec Section 9).
- British English in all UI copy.
- All FE code under top-level `frontend/`; `frontend/node_modules` gitignored.
- Do not `git push`; commit only.

`frontend/src/api.ts`:
```ts
export type JobStatus = {
  status: "running" | "done" | "failed";
  error: string | null;
};

export async function submitJob(cv: File, jd: File): Promise<string> {
  const form = new FormData();
  form.append("cv", cv);
  form.append("jd", jd);
  const res = await fetch("/jobs", { method: "POST", body: form });
  const body = await res.json();
  return body.job_id;
}

export async function getJob(id: string): Promise<JobStatus> {
  const res = await fetch(`/jobs/${id}`);
  return res.json();
}

export async function getCv(id: string): Promise<string> {
  const res = await fetch(`/jobs/${id}/cv`);
  return res.text();
}
```

`frontend/src/App.tsx`:
```tsx
import { useState } from "react";
import { getCv, getJob, submitJob } from "./api";

type Phase = "idle" | "running" | "done" | "failed";
const sleep = (ms: number) => new Promise((r) => setTimeout(r, ms));

export default function App({ pollMs = 2000 }: { pollMs?: number }) {
  const [cv, setCv] = useState<File | null>(null);
  const [jd, setJd] = useState<File | null>(null);
  const [phase, setPhase] = useState<Phase>("idle");
  const [result, setResult] = useState("");
  const [error, setError] = useState("");

  async function improve() {
    if (!cv || !jd) return;
    setPhase("running");
    setError("");
    setResult("");
    const id = await submitJob(cv, jd);
    while (true) {
      const s = await getJob(id);
      if (s.status === "done") {
        setResult(await getCv(id));
        setPhase("done");
        return;
      }
      if (s.status === "failed") {
        setError(s.error ?? "Something went wrong.");
        setPhase("failed");
        return;
      }
      await sleep(pollMs);
    }
  }

  return (
    <main>
      <h1>CV Improver</h1>

      <label>
        Your CV
        <input type="file" onChange={(e) => setCv(e.target.files?.[0] ?? null)} />
      </label>
      <label>
        Job description
        <input type="file" onChange={(e) => setJd(e.target.files?.[0] ?? null)} />
      </label>

      <button onClick={improve} disabled={!cv || !jd || phase === "running"}>
        Improve my CV
      </button>

      {phase === "running" && <p>Improving your CV — this takes a couple of minutes…</p>}
      {phase === "failed" && <p role="alert">{error}</p>}
      {phase === "done" && <pre>{result}</pre>}
    </main>
  );
}
```

Add the two handlers before `return`:
```tsx
  function download() {
    const blob = new Blob([result], { type: "text/markdown" });
    const url = URL.createObjectURL(blob);
    const a = document.createElement("a");
    a.href = url;
    a.download = "improved_cv.md";
    a.click();
    URL.revokeObjectURL(url);
    setDownloaded(true);
  }

  function rerun() {
    if (
      !downloaded &&
      !window.confirm("Rerunning will discard this draft. Download it first?")
    ) {
      return;
    }
    setPhase("idle");
    setResult("");
    setDownloaded(false);
  }
```

Replace the `done` line in the render with:
```tsx
      {phase === "done" && (
        <>
          <pre>{result}</pre>
          <button onClick={download}>Download</button>
          <button onClick={rerun}>Rerun</button>
        </>
      )}
```
